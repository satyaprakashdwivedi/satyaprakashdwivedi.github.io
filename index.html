Spark Optimizer: Claude Skill

Open-source version of the Spark optimiser I built at work, where it cut Spark compute cost 30%. Point it at Spark event and executor logs; it measures what went wrong and recommends a conflict-free config.

  • Detects skew, spill, GC pressure, wrongly sized shuffle partitions, idle executors
  • Tells heap OOM apart from container kills (exit 137) and shifts memory from heap to overhead
  • Sizes executors to your nodes so heap + overhead + Python memory always fit
  • Standard-library only · 17 tests in CI
